# 用药记录安卓版

这是独立的 Android 原生版本，数据只写入本机应用私有目录，不需要账号或网络。与 iPhone 版本的数据目前不互通。卸载应用会删除本机记录，请勿把它当作唯一的医疗记录备份。

## 体验

安装 `DoseLog-Android-debug.apk`，打开后在“药品计划”添加药品、盘点库存、填写医嘱计划。回到“今日”，点击药品对应的“已服”按钮即可记录该药品、计划剂量和手机当前时间；误触可以撤销。可以补录过去时间，“七天核对”显示计划与记录之间的差异。

提醒需要在安卓系统中允许“通知”和“精确闹钟”。没授予精确闹钟权限时，系统可能明显延迟提醒。手机关机或省电策略也可能使提醒不准时。提醒只是辅助，不代替医嘱或闹钟。

## 构建

GitHub Actions 的 `Build Android APK` 工作流使用 JDK 17、Android SDK 35、Gradle 8.13 和 Android Gradle Plugin 8.13.2，运行实际业务代码的单元测试并生成可直接安装的 debug APK。每次构建的 APK 可在工作流页面的 Artifacts 下载。debug 包由构建环境签名；将来如果换构建环境重建，同一应用可能无法覆盖安装，届时先保存数据再处理，不能直接卸载以免记录丢失。

本地有 Android SDK 时，在 `Android/` 运行 `gradle :app:testDebugUnitTest :app:assembleDebug`。当前版本没有云同步和自动备份。
